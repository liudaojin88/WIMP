# 设计文档

## 1. 技术架构
### 1.1 技术选型
- 前端：Bootstrap 5 + 原生 JS 静态页
- 后端：无（前端内存模拟数据）
- 数据存储：前端数组
- 部署：沿用现有静态页面部署

### 1.2 系统架构
- 页面：calendar-maintenance.html
- 依赖：复用头部/侧栏布局样式
- 模块：查询区、结果区（表格 + 操作栏）、新增弹窗、删除确认

## 2. 详细设计
### 2.1 前端结构
- 查询区：日期选择（input type="date"）、是否工作日下拉、适用国家下拉（示例：泰国-TH、越南-VN、中国-CN等），查询/重置按钮。
- 结果区：顶部“新增记录”按钮；表格列：日期、是否工作日、适用国家、创建人、创建时间、操作（删除）。
- 弹窗：新增记录表单（日期、是否工作日、适用国家），保存校验与提示；删除确认使用 confirm。

### 2.2 状态与数据
- dataSource: { id, date, isWorkday, country, createdBy, createdAt }
- filtered: 过滤结果
- formState: 弹窗表单数据
- 校验：日期必填，国家必填；若选择工作日=是且日期被判定为“非工作日”（周末示例或已有标记），提示确认。

### 2.3 交互逻辑
- 查询：按条件过滤 dataSource。
- 重置：清空条件、还原过滤。
- 新增：弹窗填写表单，校验通过写入 dataSource -> 刷新 filtered。
- 删除：确认后移除 dataSource 对应项，刷新 filtered。

### 2.4 UI 规范
- 复用项目配色与间距；表头浅灰，卡片阴影轻量。
- 下拉与输入统一 form-select-sm / form-control-sm。

## 3. 质量保证
- 手动校验：查询过滤、重置、新增校验提示、删除确认、表格渲染。
- 性能：数据量小，无需额外优化。
- 安全：前端渲染使用 textContent/innerText，避免 innerHTML 注入。
