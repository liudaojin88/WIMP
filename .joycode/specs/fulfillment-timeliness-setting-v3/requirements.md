# 需求文档

## 介绍
新增“履约管理-时效设置”前端静态页面，支持筛选、列表展示、增删改查弹窗占位、分页及导航入口，样式与现有Bootstrap项目一致，数据前端模拟。

## 需求

### 需求 1 - 筛选与查询

**用户故事：** 作为运营/配置人员，需要按履约模式、适用国家/地区、最后修改时间范围筛选时效设置列表，以便快速定位并查询记录。

#### 验收标准

1. 筛选项包含：履约模式下拉、适用国家/地区下拉、最后修改时间起始与结束日期各一输入（含清空），重置与查询按钮。
2. 点击“查询”按当前筛选条件过滤前端数据并刷新列表；无结果时展示空状态。
3. 点击“重置”清空所有筛选条件并恢复默认列表。
4. 时间范围支持开始<=结束校验，错误时给出前端提示，不触发查询.

### 需求 2 - 列表展示与分页

**用户故事：** 作为运营人员，需要查看时效设置数据列表，包含主要字段，并能分页浏览，方便管理。

#### 验收标准

1. 列表字段：履约模式、适用国家/地区、对客时效(d范围)、最后修改人、最后修改时间、操作列。
2. 操作列展示按钮/文本：编辑、复制新增、删除、查看。
3. 支持分页占位：页码切换、每页条数选择的前端交互与数据切分，默认每页10条。
4. 数据渲染使用前端模拟数据；时间显示格式参考截图（yyyy-MM-dd HH:mm:ss）。

### 需求 3 - 新增/编辑/复制/查看/删除交互占位

**用户故事：** 作为运营人员，需要在列表上执行新增、编辑、复制新增、查看、删除操作，占位弹窗与确认流程，便于后续接入后端。

#### 验收标准

1. 页眉区域提供“新增”按钮，点击打开新增弹窗，占位表单字段与提交按钮；提交仅做前端校验与模拟保存。
2. 编辑、复制新增、查看操作通过行级操作触发弹窗：编辑/复制可修改表单并提交；查看为只读展示；复制新增预填行数据但作为新建保存。
3. 删除操作需二次确认弹窗，确认后从前端数据移除并刷新列表/分页。
4. 弹窗表单至少包含：履约模式、适用国家/地区、对客时效范围（最小/最大天数）、备注（可选）；校验必填及范围（min<=max）。

### 需求 4 - 导航与样式一致性

**用户故事：** 作为平台用户，需要在左侧“履约管理”分组下访问“时效设置”页面，页面风格与现有系统保持一致。

#### 验收标准

1. 左侧导航在“履约管理”分组下新增“时效设置”入口并能跳转到新页面。
2. 页面整体样式沿用现有Bootstrap 5 + 全局样式，含表格、按钮、输入框间距，与截图布局相近。
3. 保留顶部工具区（帮助、用户信息等）与页面框架一致性（可复用既有layout结构）。
4. 代码遵循前端静态页实现，所有数据与交互为前端模拟，无真实接口调用。

### 需求 5 - 时效设置编辑页

**用户故事：** 作为运营人员，点击列表“编辑”需进入时效设置编辑页面，配置适用国家/地区、履约模式及各环节时效规则，完成校验后提交。

#### 验收标准

1. 编辑页包含基础配置：适用国家/地区（多选复选框，如截图国家列表）、履约模式（下拉单选，默认选中当前记录值）。
2. 时效设置表格列：环节、描述、对客时效区间（最小/最大天数输入）、参与时效计算标识（下拉“是/否”）、超期判定规则（下拉+天数字段）、异常判定规则（下拉+天数字段），字段布局与截图一致。
3. 前端静态占位：数据预填来自列表行（模拟），提交仅做前端校验与提示，无后端调用。
4. 校验：国家至少选一；履约模式必选；时效最小/最大必填且为数字且min&lt;=max；如选择超期/异常规则需填写天数；页面提供保存/取消按钮。
5. 列表页“编辑”操作跳转至 fulfillment-timeliness-edit.html（新页面）。
